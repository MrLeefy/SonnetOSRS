# Assets

All 3D models and animations in this folder are from the KayKit packs by Kay Lousberg
(www.kaylousberg.com), released under Creative Commons Zero (CC0):
Adventurers, Skeletons, Dungeon Remastered, Medieval Hexagon and Halloween Bits
(https://github.com/KayKit-Game-Assets). They are trimmed and repacked by `tools/assets.mjs`.
